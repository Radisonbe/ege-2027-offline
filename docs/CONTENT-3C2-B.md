## Разнообразие методов

Реестр классификации версионирован как v2; исторические Question/snapshot и их версии не меняются.
Уточнены 51 алиасов (включая прежние четыре); точное число проверяется по JSON,
а совпадение реестра и runtime — unit-тестом. Задачи не объявляются независимыми
лишь из-за разных чисел или имён. В частности, прямое и дробное линейное
преобразование объединены, классификация числа решений остаётся отдельно;
роль союзного слова объединяется через проверку членства внутри придаточной;
подсчёт путей с ограничением входит в семейство DAG-подсчёта с отдельными skills.

У A было 134 метки / 128 одиночных; после проверки A имеет 129 методов.
В A+B — **231** методических метки на 346 задач, **159** одиночных.
B содержит 164 метки; 102 отсутствовали среди канонических A.
Это число классификаций, а не доказательство 102 новых универсальных алгоритмов:
например, текстовая модель и прямое вычисление могут опираться на одно правило.
Дальнейшее укрупнение без потери различий навыков остаётся методической работой.

## Мини-тест

Контрольный банк больше не равен длине попытки: **до шести вопросов**.
Сначала выбираются незнакомые контрольные ID, затем по возможности разные
методы и навыки. При нехватке новых возвращаются знакомые вопросы с пояснением.
Это частичная проверка, а не объявление освоения всей темы. Все контрольные ID
исключены из быстрой практики; первый результат остаётся неизменяемым.
Существующие активные и завершённые мини-тесты не пересобираются и не обрезаются.
Функция startTopicTest по-прежнему принимает явный список для восстановления старых сценариев.
