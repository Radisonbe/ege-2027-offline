# Stage 3C.2 — качество и ограничения пакета A

## Содержательная проверка

Все 146 условий и ответы authored отдельно; числовые ответы не заполнялись
результатом того же authoring-генератора. sources/stage3c2-a-review.json содержит
проверочный код/метод, семейство, режим, пояснение альтернатив и причины исключения.

84 числовых/алгоритмических ответа вычисляются отдельно: fractions.Fraction,
классификация линейных уравнений, isqrt, независимый перебор исходов/разрядов,
разбиение префиксного кода, перебор коротких кодов, трассировка и программы путей.
Допустимый AST вычислителя ограничен; нет файлового/сетевого доступа из оракула.
Выполнение оракулов требует существующий Python 3 стандартной библиотеки:
python3 в Linux или python в Windows; EGE_ORACLE_PYTHON позволяет явно указать
доверенный установленный Python. Новая production-зависимость не добавлена.

Для 40 языковых задач проведён отдельный методический проход: контекст,
падежи/референты, основы, роль союзного слова, обособление и все варианты,
включая ошибочные. Пунктуационные экзаменационные наборы содержат полные
пять предложений, отдельные counts/reasons каждого. Местоименная связь
проверяется на уникальный референт, а не только на совпадение рода.
Это проверка автора-ассистента, а не заключение приглашённого лингвиста.
Независимое языковое ревью ChatGPT остаётся необходимым перед публикацией.

Нормативные правила сверялись с Грамотой.ру, примеры/тексты оттуда не копировались:

отрицательные числа, reversed границы, Unicode и максимальные размеры.

шингловых пар выше 0,72. Это эвристика, не доказательство семантической

Исключены c2a-exam-math-shifted-exponent, c2a-math-restore,
c2a-math-equation-domain. Последний оказался тем же условием/ответом,

консервативных skill buckets ограничена. История 10/50/100/200 разных

## Финальные уточнения поведения

- Новые прогнозы Python имеют answerFormat=python-output: сохраняются
  границы значений и регистр; многострочный краткий ответ вводится через
  пробел. `31` не равно `3 1`. Реальный stdout не меняется. Старые text-
  вопросы и математический parseNumber сохранены без изменений.
- Готовый код открывается по явному запросу после проверки или при наличии
  прежней проверки того же ID/version. Подсказки практики доступны раньше,
  экспериментальный Run сам по себе не открывает готовое решение.
- Запоздалый ответ/черновой ввод привязан к key исходного вопроса: после
  пропуска он не может стать ответом следующего. Worker проверяется
  реальным бесконечным циклом и отменой через переход.
- Snapshot reference должен быть собственным ключом pool. `toString` и
  `hasOwnProperty` не принимаются за снимок; повреждённый импорт отклоняется
  до подтверждения и не заменяет прежнее хранилище.
- Четыре explicit alias связывают старые приёмы корней/логарифмов с
  новыми вариантами; metadata старых вопросов не изменялась.


Прозрачность результатов: последний общий runner завершил 21/22; прежний
polish-browser ожидал разбор до попытки. Тест обновлён под новое требование,
все его 7 групп повторно прошли на окончательной сборке. Все 22 сценария
запущены реально, программные проверки не пропускались. Отдельно добавлен
и выполнен отказ повреждённого snapshot reference через интерфейс (11
новых PWA-групп). Исходный неуспешный лог сохранён, не подменён. Итоговые
результаты и ссылки на повторные проверки — в ignored
outputs/CONTENT3C2-REGRESSIONS-FINAL.json.
