# Stage 3C.2-G — архитектура пилота

Версия приложения остаётся 0.5.0. Main не изменяется. 699 статических заданий (614 учебных и 85 экзаменационных) считаются отдельно от 432 алгоритмических вариантов. Содержание старых статических задач сохранено, кроме согласованной редакции `c2b-russian-exam-link-workshop`: версия задания/обёртки 2, прежний ответ 4. Старые снимки версии 1 не меняются.

## Генерация

`src/domain/generators/index.ts`: 18 описателей с постоянными ID, версией, темой, подтемой, навыком, сложностью, методом, предварительными темами и размером проверенного домена. Seed — целое число от 0 до 23. Этот пилот намеренно конечный: 24 проверенных варианта на семейство, не бесконечный банк. Нет случайного текста, LLM, CDN, сетевых API и новых зависимостей.

`generateVariant(id, seed, version)` возвращает `Question` и вычислительный сертификат либо `null` для неподдерживаемого ID, версии или seed. Все вычисления ограничены, нет поиска с неограниченными повторными попытками. Точная арифметика `rational.ts` использует BigInt, сокращение НОД, положительный знаменатель и защиту от нулевого знаменателя/чрезмерных операндов.

Один метод может иметь прямое/обратное направление, разные знаки или операции. 432 варианта не являются 432 новыми методами или экзаменационными типами. Полный пробник заблокирован; экзаменационные каталоги не получают генераторы.

## Практика

«Добавить новые варианты задач» выключено по умолчанию. Кандидаты добавляются только в быструю практику; обычные мини-тесты остаются на своём статическом пуле. Общий `selectQuick` применяет выбор темы/предмета, готовность урока, предварительные знания, сложность и разрешение повторов. Готовый урок не означает освоение учеником. В смешанной подборке нет сложных задач.

Алгоритм детерминирован по seed подборки: сначала невстреченные, затем менее использованные семейства; избегает одинаковых тем/подтем подряд, когда есть альтернативы. Статические и сгенерированные кандидаты используют общий реестр метода; новый вариант не вытесняет остальные семейства своим большим размером. При исчерпании новых вариантов нужен явный выбор повторов. Пропуск, возврат, завершение раньше срока и отсутствие таймера сохранены.

Мемоизация держит только ограниченный пилот выбранных тем; ввод ответа не пересоздаёт варианты. 5000 будущих вариантов на каждом рендере не генерируются.

## Идентичность и сохранение

ID: `gen-<generatorId>-v<generatorVersion>-s<seed>`. Версия вопроса — 1, версия алгоритма хранится отдельно в `generation`. Новый алгоритм должен повышать версию генератора и получать другую идентичность. Повторное использование идентичности с другим содержимым запрещается существующим `startQuick`.

Прежний `quickPractice.snapshots` хранит один полный снимок на ID/версию вопроса; элементы сеанса ссылаются на ключ и содержат черновик, результат и ссылки на компактные тренировочные попытки. При восстановлении снимок валидируется, но **не генерируется заново**. Поэтому исчезнувший генератор/старый seed/версия остаются воспроизводимыми из backup. Не требуется держать все старые алгоритмы в приложении.

IndexedDB: прежняя физическая версия 1; пользовательская схема 2; backupVersion 2; предел 20 МиБ. Новые поля необязательны. Старые backup и предпочтения без переключателя импортируются без изменения смысла. Нет миграций, очистки или архивирования.

## Статистика

Отдельно показаны статический банк, доступные варианты и 18 семейств, встреченные варианты, правильные первые ответы без подсказок и повторные правильные ответы. `assisted` и `independentCorrect` добавляются только совместимым расширением элемента практики. Первый неверный ответ автоматически показывает прежнюю подсказку, поэтому последующее исправление не объявляется первым самостоятельным успехом. Подсказка по кнопке тоже исключает такой показатель. Решения одного семейства не считаются освоением нескольких независимых навыков. Контрольные попытки, банк ошибок и Adaptive Review не пополняются тренировочными ошибками.
