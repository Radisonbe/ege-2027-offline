# Release 0.5.0 — экзаменационный тренажёр

Утверждённый код Stage 3C.1: `93fa423a29798a9034bbf8e7813bd24123d7c764`.
Основа опубликованного main: `f91ef765dd3e34e9eefb6f9ca417a6ce1fb9419f` (0.4.0).
Рабочая ветка: `exam-trainer-3c1`.

## Состав релиза

- Все прежние 317 учебных задач, 67 тем плана / 44 готовые темы и 54
  программных задания сохранены.
- Отдельный generated-банк: 36 оригинальных экзаменационных задач;
  проектная карта ФИПИ-2027 из 74 позиций.
- Тренировки: математика №4/7, русский №16/26, информатика №4/14.
- Своя воспроизводимая подборка без повторов, сохранение и возобновление,
  первая самостоятельная попытка, подсказки, отдельные история/статистика.
- Мобильный ввод `−` и `/` по курсору; дробная черта скрыта в экзаменационном
  ответе, если формат её не допускает.
- Полный пробник **заблокирован**: покрытие ограничено, автоматической
  проверки сочинений/развёрнутых доказательств/файловых задач нет.

Этот релиз изменяет только версию приложения в package.json, настройках,
метаданных JSON-экспорта и текущем описании README, а также согласует
проверки версии. Содержимое и версии задач/карт, taxonomy, Python Runtime,
схемы, runner, IndexedDB, стили и правила оценивания совпадают с утверждённым
коммитом 93fa423. Lock-файл не содержит версии корневого приложения;
зависимости не менялись и переустановка для повышения версии не требуется.

## Сохранность данных

User schema 2, exam schema 1, backup format 2 и лимит 20 МиБ неизменны.
Никакой очистки истории или разрушительной миграции нет. Новые ресурсы PWA
сохраняются полностью, активация происходит после закрытия всех окон.
IndexedDB хранится отдельно от Service Worker cache.

Реально проверено обновление 0.4.0 → 0.5.0, сохранение обычных ошибок,
активных мини-тестов и Python-черновиков; все 36 архивных экзаменационных
снимков, карты `.1`, первый неверный ответ и исправление; старый backup с
метаданными appVersion **0.4.0** и новый экспорт **0.5.0**. Повреждённые
данные отвергаются до замены. Исторические snapshots не переписываются.

## Публикация и Android

Авторизован обычный push рабочей ветки, затем fast-forward в main при
неизменной исходной истории и обычный push main. Pages запускается только
из main, URL остаётся https://radisonbe.github.io/ege-2027-offline/.
Стабильный тег не создаётся; Stage 3C.2 не начинается. Успех deploy и
фактическая HTTPS-версия подтверждаются отдельно после завершения Actions.

На Samsung Galaxy S24 Ultra после публикации:
1. Экспортировать backup 0.4.0, дождаться готового обновления и закрыть
   все окна PWA/браузера приложения. Открыть снова: версия 0.5.0.
2. Сверить прежние ошибки, заметки, статусы, мини-тест и Python-черновик.
3. Открыть ЕГЭ: все три предмета, шесть доступных номеров; полный пробник
   недоступен. Начать свою подборку и возобновить после закрытия.
4. Проверить `−`, курсор и выделение при открытой Samsung Keyboard;
   `/` в учебной дроби и отсутствие `/` в экзаменационном числе.
5. Проверить первую попытку, подсказку и исправление; исправление не
   заменяет первый результат и не добавляет обычные учебные ошибки.
6. Дождаться всего офлайн-комплекта, включить авиарежим, полностью закрыть
   PWA и открыть снова: новая тема/ЕГЭ/Python, сохранение и JSON backup.

Аппаратная Samsung Keyboard здесь не проверялась: выполнена Chromium-
эмуляция. Предел backup 20 МиБ и частичное покрытие экзаменов остаются
явными ограничениями.
