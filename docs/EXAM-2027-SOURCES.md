Повторно прочитаны русская спецификация: таблица №16 (однородные члены и

Для русского №26 уточнение `integer` допустимо только при каноническом

Для информатики №4 текстовый краткий ответ не означает разрешение любых
типов: явно объявлены только `text`, `integer`, `bitstring`. Несовместимые
