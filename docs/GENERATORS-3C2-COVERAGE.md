Всего: математика — 240 вариантов, информатика — 192; 144 начальных и 288 средних; повышенных нет. Python и русский генераторами не охватываются. Новые темы, новые номера ЕГЭ и новые самостоятельные навыки не открываются. Полный пробник остаётся заблокирован.

Разные действия внутри метода: сложение/вычитание дробей; умножение/деление; прямое/обратное восстановление процентов; положительные/отрицательные значения; вероятность события/дополнения; конъюнкция/дизъюнкция; графы с прямой дугой/без неё и разными ветвями. Эти случаи не выдаются за отдельные семейства.

Узкая подборка только по дробям имеет 72 дополнительных условия (3 семейства), а не бесконечный ресурс. После просмотра всех вариантов без разрешения повторов начинается честный дефицит. Не гарантируется 1–2 часа новых задач для одной узкой темы. Для последующего роста наиболее полезны независимые методы текстовых моделей, обратных уравнений и разнообразных последовательностей, с расширением проверенного домена после ревью.
