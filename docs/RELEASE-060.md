# Версия 0.6.0 — расширенная офлайн-практика

Принятый кандидат: `1adb78f3cfca629c73ecfc86cd731e712f5c80ec`.
Основа опубликованной 0.5.0: `37e3ee1856cc96a26648fb52580c158120a39086`.
Релизная подготовка: 13 октября 2026 года.

## Что входит

- 1210 уникальных статических заданий: 1125 учебных и 85 экзаменационных по внутренней классификации. Это 857 новых заданий относительно 0.5.0: 146 в пакете A, 200 в B, 511 в совместном проверенном пакете ChatGPT × Codex.
- В совместном пакете приняты 475 из 500 исходных задач и 36 собственных. Все 699 прежних объектов сохраняются, отклонённые задачи остаются в реестре с причинами.
- Тематическая быстрая практика с сохранением занятия, фильтрами тем/сложности/предварительных знаний и явным разрешением повторов.
- 18 семейств генераторов, 432 конечных воспроизводимых варианта отдельно от статического банка. Варианты не считаются отдельными освоенными навыками.
- Методические исправления 51 задания русского: анализ исходного текста, правдоподобные варианты и точные разборы. QA.1 уточняет 021 и разнообразит 108/109/111; ID сохранены, версии этих четырёх вопросов повышены до 4.
- Устойчивое перемешивание проверенной группы с согласованной нумерацией разбора; старые занятия сохраняют прежний порядок. Практика по возможности чередует методы, общие тексты и конструкции.

Авторские задания не объявляются официальными заданиями ФИПИ. Экзаменационный режим сохранён, но полноценный пробник остаётся недоступен. Python Playground, текущие алгоритмы проверки и освоения, учебные функции и URL не переработаны.

## Изменения самого релизного коммита

Версия 0.6.0 согласуется в package.json, интерфейсе настроек и appVersion JSON-экспорта. README актуализирован. Вопросы, ключи, версии заданий, генераторы, Python runtime, зависимости, workflow Pages и форматы данных совпадают с принятым кандидатом. Старые документы и снимки не переписываются ради номера релиза.

## Сохранность данных

IndexedDB version 1, пользовательская schema 2, backup format 2 и лимит 20 МиБ сохранены. Результаты, ошибки, история и версии снимков, заметки, интервальные повторения, настройки и учебные Python-черновики не удаляются. Черновик свободной песочницы имеет отдельную базу и, как прежде, не входит в progress backup.

Новый полный PWA-комплект загружается заранее и активируется после закрытия всех окон. Неудачная загрузка оставляет прежний готовый комплект. Для обновления не требуется удалять PWA или очищать данные сайта. Все автоматические проверки используют синтетические данные в изолированных профилях.

## Контроль и публикация

Обязательный контроль: TypeScript, все 235 unit-тестов, content/provenance/audit, числовые и Python-оракулы, все 28 существующих браузерных наборов, генераторы, версии и ключи русского, backup/история, production-сборка и offline inventory. Фактический протокол хранится в outputs/RELEASE-060-TESTING.json.

После успешного контроля разрешены обычный push рабочей ветки и fast-forward main. Используется только существующий workflow Pages. Тег v0.6.0 создаётся после успешного deployment и проверки действующего HTTPS-сайта на точном опубликованном коммите. Итоговые SHA, ссылка Actions и live-проверки фиксируются в outputs/RELEASE-060-REPORT.md; локальная сборка не считается доказательством публикации.

## Ограничения

Частичное покрытие ЕГЭ и сложностей, отсутствие автоматической проверки развёрнутых ответов, конечный пилот генераторов, лимит backup 20 МиБ и рост истории, большой JS-чанк. Перемешивание охватывает проверенные русские вопросы с полными разборами; обычный незавершённый Quiz не сохраняет черновик. Физическая Android-клавиатура, установка и системный выбор файлов требуют проверки на устройстве.

Будущая концепция персонального тренажёра на этом этапе не реализуется; никаких дополнительных больших пакетов не создаётся.
