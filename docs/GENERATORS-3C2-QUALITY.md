# Проверка качества Stage 3C.2-G

## Независимые ответы и объяснения

Перед любой production-сборкой `checkGenerators()` запускает `scripts/generator-oracles.py` через настоящий CPython. Проверяются все 18 × 24 = 432 допускаемых варианта. Любое расхождение завершает проверку/сборку ошибкой. Проверка вызывается и из `check:content`, и непосредственно в Vite PWA buildStart.

TypeScript создаёт задачи; независимый Python использует Fraction, перебор и другие алгоритмы. Оракул отдельно реконструирует текст условия, каждую строку объяснения и решение. Это не сравнение ответа с самим ответом и не проверка только конечного числа. Параметры сертификата связываются с условием; графовые дуги и запись системы счисления дополнительно считываются из самого текста.

| Семейства | Независимый способ |
|---|---|
| Действия с дробями, целое по доле | Fraction, независимое сокращение и операции |
| Проценты | Рациональные множители и обратное восстановление |
| Линейные уравнения | Ненулевой коэффициент, перебор корней, обратная подстановка |
| Степени | Раздельное возведение в степень и деление, без использования правила суммирования показателей для эталона |
| Корень квадрата | Целочисленный isqrt и проверка квадрата |
| Вероятность | Явный перечень равновозможных шаров и подсчёт благоприятных |
| Перевод и разряды | Независимая разрядная сумма / обратное преобразование записи |
| Неизвестная цифра/основание | Перебор допустимых значений с проверкой единственности |
| Равномерный код | bit_length, обе границы степени двойки |
| Логика | Перечень целых чисел, условия через равносильное отрицание |
| Граф | DFS по дугам, проверка отсутствия повторных дуг/циклов |

## Границы и отказы

Все 432 условия различны. Ноль, отрицательные числа, сокращаемые дроби, прямые и обратные проценты присутствуют. Seed вне 0–23, дробные/нечисловые seed, неподдерживаемые ID и версии дают отказ. Нулевой знаменатель, деление на ноль и операнд больше 10^9 отклоняются точной арифметикой. Уравнения имеют ровно один корень в конструкции; проверка ненулевого коэффициента доказывает единственность в R, перебор отдельно подтверждает созданный корень. Ответы конечны, диапазоны ограничены, вероятности между 0 и 1, цифры допустимы.

Из 432 штатных генераций отказов 0. Негативные тесты специально создают повреждённые сертификаты, неверные ответы/условия/промежуточные действия: оракул обязан отказать, они не входят в пользовательский банк.

Обнаружено и устранено при разработке: повторяющиеся условия степеней/графов в первоначальной параметризации; неподходящие ID подтем; кодировка stdin проверочного Python на Windows. Финальные массовые проверки подтверждают 432 уникальных условия, корректные ссылки и UTF-8. Реестр provenance фиксирует исходники оригинальных шаблонов. Чужие материалы не использованы.

Тесты повреждённого backup проверяют генераторные метаданные и связи тренировочных попыток. Старый снимок восстанавливается после отключения старой версии генератора; изменение условия под тем же ID отклоняется. Первая самостоятельная контрольная попытка и Python Runner не изменены.

Методическая граница: каждый метод представлен 24 небольшими вариантами. Изменение чисел само по себе не объявляется новым методом. Для будущего расширения домена нужно повторить полный независимый прогон; бесконечное число корректных вариантов сейчас не доказано.

Дополнительно проверены 211 зарезервированных контрольных вопросов: ID генераторов не входят в контрольное распределение; буквальные пары дробей и операции (с учётом перестановки при +/умножении) из генераторов не совпадают с контрольными выражениями. Эта проверка не объявляется универсальным доказательством семантической непохожести всех задач: методы намеренно общие, условия и назначение разделены.

## Фактический финальный прогон

- TypeScript: успешно; полный unit-набор: 160/160.
- Все 432 seed: проверены ответ, условие, каждая строка объяснения; повреждённые сертификаты отказаны.
- Общий набор: 24 сценария. В исходном запуске 23/24 (163 PASS-группы): одному прежнему exam-browser ошибочно передана сборка 0.3.1 вместо обязательной 0.4.0; тайм-аут был на ожидании старой версии до проверки нового приложения.
- Повтор exam-browser с `outputs/release040-checked`: 8/8 групп, код выхода 0. Никакая продуктовая проверка не отключалась. Запускатель получил отдельный необязательный аргумент для базовой 0.4.0.
- Пилот на окончательных production-байтах: 9/9 групп, включая обновление 0.5.0, холодный офлайн, backup, дроби и реальную информатическую подборку.
- Эффективный итог с явно указанными повторными запусками: 24/24 сценария, 172 PASS-группы. Это не утверждение, что исходный единый запуск имел код 0: его журнал и исходный nonzero сохранены.
