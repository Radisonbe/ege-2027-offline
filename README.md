# ЕГЭ 2027 — локальный учебный центр

Первая техническая итерация отдельного приложения на React + TypeScript + Vite. Интерфейс и существующий учебный комплект перенесены с https://ege-2027-radisonbe.sonberadi.chatgpt.site. Это пока не стабильная PWA: service worker, установка и импорт/экспорт ещё не реализованы.

## Запуск

Требуется Node.js 20.19+ / 22.12+ и современный Chromium. Зависимости зафиксированы в `pnpm-lock.yaml`; установочные скрипты отключены. Использован Node.js 24.19.0.

```text
pnpm install --frozen-lockfile --ignore-scripts
pnpm dev
pnpm build
pnpm test
pnpm preview
```

Разработка: http://127.0.0.1:5173. Предпросмотр сборки: http://127.0.0.1:4173. Оба адреса доступны только на этом компьютере. Это средства разработки, а не серверная часть приложения. Для установки на Android способ HTTPS-размещения будет согласован отдельно.

## Структура

- `src/components` — общие элементы интерфейса, тесты и предметные тренажёры.
- `src/pages` — главная, предмет, тема, ошибки, повторение, прогресс, настройки и короткие занятия.
- `src/domain` — типы, проверка формата и ответа, даты, правила учёта попыток и статистики.
- `src/data` — статический комплект эталона, каталог и преобразование метаданных.
- `src/storage` — асинхронный интерфейс хранилища и реализация на IndexedDB.
- `src/state` — загрузка состояния и последовательное сохранение изменений.
- `src/styles` — перенесённые стили и дополнения для локального интерфейса и мобильных экранов.
- `public` — локальная иконка.
- `work` — материалы анализа, безопасный извлекатель данных, проверочные сценарии и журнал безопасности.
- `outputs` — отчёт и снимки результатов проверки.
- `dist` — производственная сборка.

## Данные

План содержит 67 тем, 19 готовых объяснений, 67 исходных вопросов и три предложения для синтаксического тренажёра. Из 67 вопросов 57 используются в мини-тестах, 10 относятся к существующим лёгким заданиям. 48 тем сохраняют состояние плана без выдуманных уроков. Числа и шаблоны интерактивных упражнений воспроизводят исходные тренажёры; большой банк не генерировался.

`src/data/reference.json` содержит URL публичного ресурса эталона, дату извлечения и SHA-256. Данные прочитаны из синтаксического дерева: исходный JavaScript не импортировался и не исполнялся. Объяснения сохранены как дерево разрешённых тегов с текстом; `dangerouslySetInnerHTML` не используется. Код Python является текстом.

Перенесённые задания обозначены `origin: custom`, `sourceType: training`, с URL эталона. Точное происхождение авторства/генерации каждого задания источник отдельно не обозначает; принадлежность ФИПИ не предполагается. `sourceYear`, `subtopic` и `examTaskType` оставлены `null`, сложность — `unspecified`, кроме исходных `easy`. Предусмотрены `official`, `generated`, `reconstructed`, `custom`, а также `requires` и `related`; новые связи не выдуманы.

## Прогресс

IndexedDB `ege-local-center`, хранилище `progress`, документ `current`. Формат: `app`, `schemaVersion`, `contentVersion`, темы, попытки, ошибки, повторения, учебная активность и настройки. Сохраняется атомарно и последовательно. Материалы отделены от прогресса. Другой формат сохранения не перезаписывается. Для большого банка можно добавить отдельные индексированные хранилища через тот же интерфейс.

Неверный формат ответа не создаёт попытку. Корректный, но неверный ответ сохраняет попытку и отдельную ошибку. Правильный ответ не удаляет прошлые ошибки. Разные решённые задания считаются по идентификатору. Серия дней основана на местных датах ответов и явно отмеченных занятий. Интервалы повторения: 1, 3, 7, 14, 30 дней. Статус «Уверенно» остаётся самооценкой.

Данные привязаны к адресу браузера: порты 5173 и 4173 имеют отдельные сохранения. Для проверки использован 4173; основной экземпляр 5173 оставлен без тестовых попыток. В этой итерации не гарантируется совместное редактирование прогресса несколькими одновременно открытыми вкладками; это следует проверить перед стабильным релизом.

## Ограничения этапа

Нет PWA, гарантированного запуска без сети, импорта/экспорта, облака, аккаунтов или исполнения Python. Дополнительные визуальные схемы после синтаксического ответа и сравнение степеней в кодировании ещё требуют доведения до полного соответствия эталону. Общие объяснения, проверка, подсказки и решения уже перенесены.

Полный отчёт этапа и результаты проверки находятся в `outputs/STAGE-1-REPORT.md`.
