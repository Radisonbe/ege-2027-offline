# ЕГЭ 2027 — локальный учебный центр

Версия **0.6.0**, React + TypeScript + Vite. Офлайн-PWA для тематической подготовки по математике, русскому языку, информатике и Python.

Сайт: https://radisonbe.github.io/ege-2027-offline/.

## Учебный комплект

- **1210 уникальных статических заданий:** 1125 учебных и 85 экзаменационных по внутренней классификации проекта.
- **857 новых статических заданий относительно опубликованной 0.5.0:** пакет A — 146, пакет B — 200, совместный проверенный пакет ChatGPT × Codex — 511 (475 принятых из исходных 500 и 36 собственных задач).
- **18 семейств генераторов и 432 конечных воспроизводимых варианта** отдельно от статического банка. Варианты одного метода не считаются отдельными освоенными навыками. Новые варианты включаются в быструю практику по выбору пользователя.
- План из 67 тем, 44 заполненных модуля; дополнительные материалы углубляют существующие темы. Готовый материал не означает, что ученик освоил тему.
- Python Playground, тематическая быстрая практика, независимые мини-тесты, повторение ошибок и сохранение прогресса.

Задания авторские учебные, **не официальные задания ФИПИ**. Связи с типами ЕГЭ помогают ориентироваться в темах, но не доказывают эквивалентность настоящему экзамену. Раздел «ЕГЭ / Пробники» сохраняется; полный пробник недоступен из-за частичного покрытия и отсутствия автоматической проверки развёрнутых ответов.

В русском пересмотрены 51 задание на анализ текста, грамматические основы и пунктуацию. Каждое утверждение проверяется по словам и конструкциям исходного текста. В проверенной группе варианты перемешиваются устойчиво для занятия; разбор следует экранному порядку, а старые занятия сохраняют исходный порядок. В быстрой практике по возможности чередуются методы, исходные тексты, конструкции и сложности при сохранении выбранных тем и ограничений повторения.

Описание изменений: [релиз 0.6.0](docs/RELEASE-060.md). Решения независимого ревью: [CHAT500-QA](docs/CHAT500-QA.md), [CHAT500-QA.1](docs/CHAT500-QA1.md).

## Запуск и сборка

Требуется современный Chromium. Проверено на Node.js 24.19.0, pnpm 11.25.0 и Microsoft Edge. Зависимости закреплены в `pnpm-lock.yaml`; установка локальных программ не нужна для работы опубликованной PWA.

```text
pnpm install --frozen-lockfile --ignore-scripts
pnpm dev
```

Разработка: http://127.0.0.1:5173/. Service Worker в этом режиме отключён.

```text
pnpm exec tsc --noEmit
pnpm test
pnpm run build:public
pnpm preview
```

Готовая сборка доступна по http://127.0.0.1:4173/. Открытие через `file://` не поддерживается. Для первой загрузки нужен HTTPS или localhost; после сохранения полного комплекта сервер и сеть для занятий не требуются.

## Практика и проверка ответов

В практике можно исправлять решения: тренировочная активность хранится отдельно от контрольных попыток и основного банка ошибок. Мини-тест сохраняет первый самостоятельный ответ; исправление после разбора не заменяет его результат. Новый мини-тест выбирает до шести вопросов из доступного контрольного пула; старые более длинные занятия не обрезаются.

В «Повторении на сегодня» доступны 5/10/15/20 вопросов и выбор предмета. Приоритеты опираются на сохранённые ошибки и историю; статусы тем можно менять вручную. «Уверенно» — самооценка, а не прогноз балла ЕГЭ. Если подходящих заданий мало, подборка сокращается; другие темы и повторы без разрешения не подставляются.

Ответ проверяется по значению, не по позиции варианта. Неверный формат не создаёт попытку. Правильный ответ после ошибки не удаляет историю. Запуск Python-программы — эксперимент; учебный результат записывается отдельной проверкой. Косметические варианты не создают новых семейств методов.

## Python Playground

Локальная песочница поддерживает код с отступами, stdin и интерактивный `input()`, stdout, traceback, остановку и лимит выполнения. Pyodide 314.0.7 / CPython 3.14.2 и пять runtime-файлов поставляются внутри офлайн-комплекта; CDN и сервер для выполнения не нужны.

Python работает в Worker внутри sandbox iframe с непрозрачным origin. Учебная IndexedDB и DOM приложения не передаются; сетевые обращения ограничены CSP и runtime-политикой. Остановка и timeout восстанавливают чистый runtime. Жёсткий лимит RAM не гарантируется. Ожидаемые результаты учебных тестов сравниваются вне Worker; hidden tests в публичном клиенте не являются секретной экзаменационной системой.

Черновик свободной песочницы хранится отдельно в `ege-python-playground/drafts/current` и **не входит в backup прогресса**: при переносе его нужно копировать отдельно. Черновики программ учебных заданий входят в JSON-backup. Подробнее: [Python Playground](docs/PYTHON-PLAYGROUND.md).

## Полный офлайн и обновления

Vite создаёт SHA-256-инвентарь всех ресурсов сборки и `public`. Service Worker сохраняет полный банк, объяснения и Python runtime, включая ещё не открытые разделы. Перед отключением сети дождись сообщения «Полный учебный комплект сохранён» в настройках.

Каждая сборка имеет отдельный кэш. Новая версия заранее загружается целиком и ждёт закрытия всех окон приложения. Принудительный `skipWaiting` не используется. Повреждённое или неполное обновление не заменяет прежний готовый комплект. Кэш Service Worker отделён от IndexedDB. Не очищай данные сайта и не удаляй PWA для обычного обновления.

Нет обязательных внешних шрифтов, CDN или API для занятий. Ссылки на источники требуют интернета, но не участвуют в проверке ответов. Исходный адрес и относительный `base: './'` сохраняются; hash-навигация работает под `/ege-2027-offline/`.

## Прогресс и резервные копии

Учебная IndexedDB: `ege-local-center`, физическая версия 1, хранилище `progress`, ключ `current`. Пользовательский документ имеет `schemaVersion: 2`; старый v1 импортируется с сохранением оригинала. Встроенный банк хранится отдельно. Исторические вопросы в ошибках и занятиях используют собственные снимки и не переписываются при обновлении банка.

Сохраняются результаты, ошибки, заметки, интервальные повторения, история, настройки и учебные Python-черновики. Записи выполняются последовательно и атомарно. JSON-экспорт ждёт окончания очереди записи.

```text
format: ege-progress-backup
backupVersion: 2
appVersion: 0.6.0
createdAt: ISO timestamp
data: StudyState с schemaVersion: 2
```

Лимит backup — **20 МиБ**. Экспорт включает историю и нужные снимки, а не весь поставляемый банк. Импорт проверяет размер, версии, типы, уникальность ID и связи до замены. Повреждённые данные ничего не меняют. После просмотра состава требуется явное подтверждение; импорт заменяет прогресс, а не объединяет его. В одной транзакции сохраняется копия прежнего прогресса под уникальным `before-import:<дата>:<UUID>`.

Прогресс привязан к origin. `localhost`, разные порты и production URL имеют разные данные; перенос выполняется JSON-экспортом/импортом. Перед импортом закрой остальные окна приложения. Параллельное редактирование несколькими окнами не объединяется. Обратный импорт новых данных в старое приложение не обещается. При росте истории лимит 20 МиБ остаётся ограничением; автоматической очистки нет.

## Проверки

Полный unit-набор — 235 тестов. Существующий полный браузерный реестр включает 28 наборов: практика, русский, числовой ввод, программные эталоны и ошибочные решения, Playground, генераторы, backup, история, PWA и обновления. Сценарии работают с синтетическими данными в отдельных профилях Edge; реальные пользовательские профили не используются.

```text
pnpm run check:content
pnpm run audit:public
node scripts/check-offline-build.mjs <build-directory>
node work/tests/run-chat500-qa-browser.mjs <playwright-runtime-directory> <prefix-build> <relative-build> <old-prefix-build> <old-exam-build>
```

Полный браузерный прогон требует уже настроенных Playwright/Edge и исторических сборок. Некоторые сценарии проверяют конкретную старую версию: для экзаменационного перехода используется сборка 0.4.0, для обновления рабочего комплекта — 0.5.0. Числовые и Python-оракулы используют локальный Python 3 со стандартной библиотекой; при необходимости путь задаётся `EGE_ORACLE_PYTHON`. Это инструмент проверки, а не зависимость PWA.

Фактические результаты релиза, commit SHA, Actions и проверка действующего HTTPS-сайта сохраняются в локальных `outputs/RELEASE-060-REPORT.md` и `outputs/RELEASE-060-TESTING.json`.

## GitHub Pages

Используется существующий `.github/workflows/pages.yml`: push в `main`, Node.js 24, pnpm 11.25.0, установка по lock-файлу без lifecycle-скриптов, TypeScript, unit, audit, content, production build и проверка финального offline inventory. Deployment выполняется только после успешных проверок. Официальные Actions закреплены на commit SHA.

Публикуется только production `dist`: HTML, CSS/JS, иконки, manifest, Service Worker, offline inventory, локальный Python runtime и уведомления о лицензиях. Исходники, тесты, пользовательский прогресс, профили, backup и промежуточные сборки в Pages artifact не входят. Комплект включает 35 precached ресурсов; `sw.js` и `offline-inventory.json` обслуживаются дополнительно.

## Ограничения и Android

Полный пробник недоступен; покрытие номеров, тем и сложностей частичное. 432 варианта не являются бесконечным банком или 432 освоенными навыками. Перемешивание ограничено проверенными русскими вопросами с полным разбором каждого варианта. Незавершённый обычный Quiz по-прежнему не имеет сохраняемого черновика; сохраняемые занятия и завершённые попытки восстанавливаются. Большой JS-чанк и рост истории остаются известными ограничениями.

После обновления на настоящем Android/Samsung: сохранить backup 0.5.0, дождаться готового комплекта, закрыть все окна, открыть 0.6.0 и сверить историю/ошибки/заметки/настройки/черновики. Затем проверить авиарежим и холодный запуск, экранную клавиатуру, установку PWA и системный выбор JSON. Браузерная эмуляция не подтверждает аппаратную клавиатуру или поведение конкретного телефона.

## Структура и история проекта

- `src/data` — банк, темы, объяснения, таксономия и карты.
- `src/domain` — проверка ответов, прогресс, повторение, практика, backup и генераторы.
- `src/storage` — IndexedDB; `src/python` — изолированный runtime/runner.
- `src/pages`, `src/components` — интерфейс; `public` — поставляемые ресурсы.
- `work/tests` — тесты; `outputs` и `dist` — локальные игнорируемые артефакты.

Исторические отчёты сохраняют фактические числа и версии своего этапа: [0.5.0](docs/RELEASE-050.md), [учебные режимы](docs/STUDY-FLOW.md), [пакет A](docs/CONTENT-3C2.md), [пакет B](docs/CONTENT-3C2-B.md), [генераторы](docs/GENERATORS-3C2.md), [авторский пакет](docs/CHAT500-REVIEW.md), [собственные задачи](docs/CODEX500-REVIEW.md). Их старые упоминания 0.5.0 не являются текущими метаданными приложения.
